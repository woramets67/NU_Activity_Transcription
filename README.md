# NU Activity Transcript

แอปเก็บชั่วโมงจิตอาสาและกิจกรรมคณะของนิสิต มน. (วิชา 273387)

- รายการกิจกรรม ค้นหา กรองตามประเภท และลงทะเบียน
- Dynamic QR เปลี่ยนทุก 10 วินาที สแกนรับชั่วโมง
- ตรวจตำแหน่ง GPS ต้องอยู่ห่างผู้คุมไม่เกิน 200 เมตร
- Transcript สรุปชั่วโมงแยกจิตอาสาและกิจกรรมคณะ
- โหมดผู้คุม สร้างกิจกรรม จัดการรายชื่อ ให้ชั่วโมงเอง
- ประกาศถึงผู้ลงทะเบียน พร้อมกล่องแจ้งเตือน
- Export รายชื่อเป็น Excel
